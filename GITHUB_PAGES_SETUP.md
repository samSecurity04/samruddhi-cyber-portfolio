# Enable GitHub Pages (one-time, samSecurity04 account)

The build workflow is working. The site files are on the `gh-pages` branch.

If the live URL returns 404, complete these steps once:

1. Open https://github.com/samSecurity04/samruddhi-cyber-portfolio/settings/pages
2. **Build and deployment** → **Source** → **Deploy from a branch**
3. **Branch:** `gh-pages` · **Folder:** `/ (root)` → **Save**
4. Wait 2–5 minutes, then open https://samSecurity04.github.io/samruddhi-cyber-portfolio/

Do **not** set Source to "GitHub Actions" for this project — we deploy via the `gh-pages` branch.
